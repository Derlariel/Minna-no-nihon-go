# Kotoba · ติวมินนะ โนะ นิฮงโกะ บทที่ 1–6

เปิด `index.html` ในเบราว์เซอร์เพื่อเริ่มใช้เว็บ หรือใช้เซิร์ฟเวอร์ไฟล์สถิติตามปกติ เว็บไม่มีขั้นตอน build และไม่ต้องติดตั้งแพ็กเกจ

- หน้าเรียนมีคำศัพท์และคันจิคัดเลือก คำอ่านฮิรางานะ/ฟุริงานะ โรมาจิ คำแปลไทย ไวยากรณ์ และตัวอย่าง
- มีโจทย์แต่งใหม่ 72 ข้อ แยกเป็น A, B, C และท้ายบท บทละ 12 ข้อ พร้อมเฉลยหรือแนวคำตอบ
- ข้อสอบจำลอง 33 ข้อครอบคลุมทั้ง 7 หมวดในสไลด์ `IMG_2341.pdf` หน้า 8 ข้อคำตอบสั้นตรวจด้วยรายการคำตอบที่รองรับ ข้อเขียนปลายเปิดมีตัวอย่างและเกณฑ์ให้ตรวจเอง
- ตารางช่วยจำครอบคลุมชั่วโมง นาที ปี เดือน วันที่ วันในสัปดาห์ เงิน ชั้น อายุ และกริยาสุภาพ 4 รูป
- บทที่ 7–12 จากเว็บเดิมเข้าถึงได้ในสารบัญ และยังเก็บดาวคำศัพท์กับคะแนนแบบเลือกตอบในเบราว์เซอร์ได้
